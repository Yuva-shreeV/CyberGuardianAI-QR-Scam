# CyberGuardian AI – QR Scam Risk Assessment System

## Project Overview
CyberGuardian AI is an Explainable AI-Based Contextual QR Scam Risk Assessment and User Decision Support System. It helps users assess the potential risks associated with QR codes before making payments or interacting with them.

## Objectives
- Detect potentially malicious and benign QR codes.
- Assess QR-related security risks using Machine Learning.
- Provide understandable explanations for prediction results.
- Help users make informed decisions before proceeding with QR-based payments.

## Key Features
- QR Code Scanning
- Machine Learning-Based Risk Prediction
- Safety Score and Risk Level Assessment
- Explainable AI-Based Risk Factors
- Scan History
- User Login
- Chatbot Assistance

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Machine Learning:** Random Forest and other ML algorithms
- **Explainable AI:** SHAP
- **Database:** MySQL

## Project Structure
- `backend/` – Backend logic and API services
- `mobile_app/` – Frontend application
- `ml_model/` – Trained machine learning models
- `run.py` – Application startup file

## Project Purpose
The main purpose of CyberGuardian AI is to improve QR payment safety by providing risk assessment, understandable predictions, and user decision support.
