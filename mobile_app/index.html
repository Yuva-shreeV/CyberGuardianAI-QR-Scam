ABOUT THE PROJECT

CyberGuardian AI

An intelligent QR security assistant designed to identify potentially dangerous QR destinations.

🛡️

What is CyberGuardian AI?

CyberGuardian AI analyzes the destination hidden inside a QR code and predicts whether it is safe or potentially phishing. For UPI payment QR codes, it also checks payment details and highlights security risks before you pay.

🤖

Machine Learning

Machine learning techniques are used to analyze URL characteristics and classify potentially malicious destinations.

🔍

Explainable AI

Explainable AI helps provide understandable reasons behind the security prediction.
